# Secure Web Application with Authentication & Security Logging

## About
A Python Flask web application demonstrating secure user authentication and basic security logging.

## Features
- User registration and login
- Argon2 password hashing
- Parameterized SQL queries to help prevent SQL injection
- Session management and logout
- Logging of failed login attempts

## Technologies Used
- Python
- Flask
- SQLite
- Argon2
- Logging

## How to Run

1. Install Python.
2. Install the required packages:

   pip install flask argon2-cffi

3. Run the application:

   python app.py

4. Open your browser and visit:

   http://127.0.0.1:5000

## Disclaimer
This is an educational demonstration project, not a production-ready application.
